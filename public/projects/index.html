Projects

ALUG@UCI projects is our git server where we encourage UCI students to create and work on open-source projects.

Why open-source?

Open-source software (OSS) is the core of Linux and other (very important) software. OSS is sometimes known to be a way for programmers to break into software engineering, since contributing to OSS demonstrates the ability to read and work with other people’s code in sometimes very large or widely-used codebases.

Aside from personal development, open-source is a community service, bringing people together to accomplish a lot more. ALUG@UCI-hosted projects aims to be an open platform for student-led projects and to enhance the UCI student developer community.

What’s in it for me?

create cool projects with fellow students

get into open-source by contributing or starting a project

develop practical skills, like reading code and using git

How do I start!

Checkout our git server, where you can find or start projects. Note that projects on our git server do not have to be open-source, so feel free to use it as a regular git server for your side projects.
